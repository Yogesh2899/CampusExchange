# Suggested 8–10 minute demonstration

1. **Introduce the problem (1 minute):** explain campus resale and show the architecture/ER diagrams.
2. **Student account (1 minute):** register/sign in and show the private profile page.
3. **Seller journey (2 minutes):** create a book listing, add a photo, and show My listings. Mention edit restrictions when requests are pending.
4. **Buyer journey (1 minute):** use a second browser profile/private window to sign in as a buyer; search and send a request. Separate browser sessions avoid accidentally switching both accounts together.
5. **Complete a sale (1 minute):** accept as seller; show SOLD, trade history, and the buyer's seller review. Explain offline payment/handover.
6. **Moderation (1 minute):** show admin categories, remove a separate available demo listing, and suspend/restore a demo student. Use disposable demo records rather than your own admin account.
7. **Engineering evidence (1–2 minutes):** show TEST_RESULTS.md, the concurrency test and READ_COMMITTED service transaction, the SQL script, and explain persistent MySQL storage.

Before presenting: restart the final JAR, check the port, register demo accounts, prepare an appropriate JPEG/PNG, and capture the views listed in SCREENSHOT_GUIDE.md. Add your student/course details to the report. Keep passwords and .local files out of the presentation.
